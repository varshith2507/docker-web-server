🚀 Docker Web Server Project

DevOps Internship Project 2026

📌 Project Overview

This project demonstrates how Docker can be used to deploy and manage a web server using Nginx. The webpage is hosted inside a Docker container and accessed through port mapping.

🛠 Technologies Used

  • Docker
  • Nginx Web Server
  • HTML5
  • CSS3
  • Git & GitHub
  • Windows 11

✨ Features Implemented

  • Containerized Web Server
  • Docker Image Management
  • Port Mapping (8080 → 80)
  • Custom HTML Deployment
  • Container Start, Stop and Remove Operations
  • Version Control using Git
  • Project Hosting on GitHub

📚 Concepts Learned

  • Docker Images and Containers
  • Nginx Configuration
  • Volume Mapping
  • Container Lifecycle Management
  • Git and GitHub Workflow

🌐 Access Information

Server URL: http://localhost:8080
